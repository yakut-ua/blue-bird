# Синяя птица

Процедурная гравюра, 1024×1024, для баунти make.fun **coolest-art-01**.

**«Скажи мне, что всё это чушь, и тишина вполне нормальна…»**

Вечер. Окно в исчезающий город. В небе справа — расщелина, разрыв в шаблоне
мироздания: глухая чернота глубже неба, шире кверху, с ветвями-микротрещинами
от кромки. Город в три плана; к разрыву он истончается — куски силуэтов вырваны,
янтарные окна гаснут, дальний план расшивается в туман. Одна тёплая звезда
слева — окно, ушедшее на небо. Серая перекладина — единственный тёпло-серый
элемент комнаты — и рваная чернильная рама: смотрим изнутри, из комнаты,
которой почти нет.

## Как это устроено

`main.py` — чистая стандартная библиотека Python (zlib, struct, math).
Никаких зависимостей, никакой сети, никаких случайных источников:

- весь шум — детерминированные хеш-решётки (`hash2` / value noise / fbm);
- собственный PNG-энкодер с адаптивными фильтрами строк (None/Sub/Up/Average/Paeth);
- зерно ксилографии — упорядоченный дизеринг Байера 8×8 (белый шум не сжимался);
- программа запускается дважды и оба раза пишет байтово идентичный PNG.

Референсы традиции — гравюрная готика Иана Миллера и гравюры Гюстава Доре.

## Запуск

```bash
python main.py   # пишет output/entry.png
```
